## プルダウンメニュー

プルダウンメニューから以下が出来るようにする。

- 編集中のデータをファイルに保存 (Ctrl+S)
- 名前を付けて保存 (Ctrl+Shift+S)
- ファイルに保存したデータを読み込む (Ctrl+O)。ファイル形式は .rdjson。
- 編集中のデータを全削除。実行前に確認ダイアログを表示する。
- 最後の図形への操作をundoする (Ctrl+Z)。最大500手順まで遡る。
- 全体表示 (Ctrl+0)。全図形が画面内に収まるようビューを調整する。
- 縦断線形ウィンドウを開く (Ctrl+Shift+V)。


## 編集画面

編集画面では以下を可能にする。

- 右プレーンの表示・非表示を切り替える。
  デフォルトは非表示。ツールバーのチェックボックスまたはメニューから切り替える。

- ビューの操作:
  - マウスホイールでズームイン・ズームアウト。ズームはマウス位置を中心に行う。
  - 何もない場所を左ボタンでドラッグすることでビューをパンする。
    図形のない場所で押して4ピクセル以上動かした場合にパンと判定する。
    4ピクセル未満の移動はクリック（選択解除）として扱う。
    ドラッグ中はカーソルが握った手の形になる。
  - 中ボタン（ホイールクリック）でドラッグすることでもビューをパンできる。

- ツールバーのボタンまたはショートカットキーでモードを切り替える。
  - 選択モード [S]
  - 直線モード [L]
  - 円モード [C]

- 直線モードでは、マウスを左clickする毎に、折れ線を描く。
  1回目のマウスの左clickの位置 p を記憶し、
  2回目以降の左clickでは、その位置を q とすると、
  参照始点と始点が p、参照終点と終点が q の直線を追加し、
  以降の直線の追加の度に、直線と直線の折れ線接続を行う。
  [Esc]キーで折れ線の連続入力をリセットする。
  ラバー線により次の直線の予定位置を表示する。

- 円モードでは、マウスの左clickで円の中心を決め、
  そのままdragで半径を仮に示すラバー線（円）を表示し、
  左ボタンを離すことで半径を確定させる。

- 選択モードでは、以下を可能にする。

  - 左クリックで図形を選択する。Shiftキーを押しながら左クリックで複数選択。
    何もない場所をクリック（4px未満のドラッグ）すると選択を解除する。
    ホバー中の図形はハイライト表示される。

  - 1図形が選択されている場合、右プレーンに図形の各種プロパティを表示する。

  - 1図形が選択されている場合、Delキーで図形を削除する。
    直線を削除すると、その直線に関連するクロソイドも削除される。
    円を削除すると、その円に関連するクロソイドも削除される。

  - 1直線が選択されている場合、以下のハンドルが表示される:
    - 参照始点・参照終点（灰色）: ドラッグで参照点を移動できる。
      参照点が移動した場合、線分端点は新しい直線上に再投影される。
      この直線を定義に含むクロソイドは、直線に合わせて自動再計算される。
      スムーズ接続されている場合、関連する円も連動して移動する。
    - 線分の始点・終点（赤色）: ドラッグで端点を移動できる。
      端点は参照点が決定する直線上に束縛される。
    - 折れ線接続またはスムーズ接続されている場合、共有参照点の位置に
      橙色の交点ハンドル（`shared_pt`）が1つ表示される。
      共有点と同位置にある `line_ref_start/end` や `seg_start/end` ハンドルは
      非表示になり、`shared_pt` のドラッグで確実に両直線が追従する。

  - 1個の円が選択されている場合、以下のハンドルが表示される:
    - 中心点（灰色）: ドラッグで中心を移動できる。
      スムーズ接続された円の場合、中心は角の二等分線上に束縛される。
      移動した場合、半径は維持され、円弧端点の角度も維持される。
      この円を定義に含むクロソイドは、円に合わせて自動再計算される。
    - 半径ハンドル（緑色、円の右端）: ドラッグで半径を変更できる。
      変更した場合、この円を定義に含むクロソイドは自動再計算される。
    - 円弧の始点・終点（赤色、円弧がある場合）: ドラッグで移動できる。
      端点は円周上に束縛される。

  - 2直線が選択されている場合、右プレーンから以下のいずれかを操作できる:
    - 折れ線接続（常に有効）
    - スムーズ接続（常に有効）
    - 接続解除（この2直線の接続が存在する場合のみ有効、それ以外はdisable）
    折れ線接続またはスムーズ接続を行うと、交点に橙色の交点ハンドルが表示される。
    交点ハンドルをドラッグすると、2直線の参照点・端点が連動して移動する。
    スムーズ接続の場合、関連する円も連動して移動する。

  - 直線と円が選択されている場合、右プレーンにクロソイド接続の状態を表示し、
    以下の操作をその状態に応じて有効/無効を切り替えながら提供する:

    この直線・円の組に対するクロソイドの本数を n とすると、

    操作                n=0     n=1               n=2
    ----------------    ------  ----------------  ------
    クロソイドを追加    有効    有効（反転側追加） disable
    クロソイドを削除    disable 有効              disable
    クロソイドを反転    disable 有効              disable

    n=2 の場合、2本のクロソイドは互いに逆の反転フラグを持つ。

  - クロソイドが選択されている場合、右プレーンから以下を操作できる:
    - カーブ方向（左カーブ/右カーブ）の表示
    - 線分とのsnap機能のon/off切り替え
    - 円弧とのsnap機能のon/off切り替え
    - クロソイドの反転ボタン
      同じ直線・円の組に対してクロソイドが2本ある場合はdisable

- 図形の色分け:
  - 直線の参照線（破線）: 灰色
  - 線分: 青色
  - 円（円弧なし）: 紫色（実線）
  - 円（円弧あり）: 薄紫色（点線）
  - 円弧: 紫色（太い実線）
  - クロソイド: 緑色
  - 選択中の図形: 黄橙色（ハイライト）
  - ホバー中の図形: 黄色（ハイライト）
  - 参照点・中心点のハンドル: 灰色
  - 端点のハンドル: 赤色
  - 半径ハンドル: 緑色
  - 交点ハンドル: 橙色
  - 無効なボタン: 薄いグレー（disable スタイル）


## 右プレーン

### マウス座標表示

編集画面上にマウスカーソルがある間、右パネルの上部に
カーソルのワールド座標（X, Y）をリアルタイムで表示する。
精度は小数点以下3桁。

### 図形の選択

設計画面で図形を左クリックして選択する代わりに、
右パネルに複数あるcombo boxから、ニックネームを選択し、
最後の「選択」ボタンを押すことで、図形を選択することが出来る。
combo boxは通常 2個あるが、右パネルで増減ボタンから
個数を増減させることが出来る。

コンボボックスには以下の図形が表示される（シーン変更時に自動更新）:
- 直線: `{ニックネーム} [直線]`
- 線分: `線分#{id} (直線:{直線のニックネーム}) [線分]`
- 円:   `{ニックネーム} [円]`
- 円弧: `円弧#{id} (円:{円のニックネーム}) [円弧]`
- クロソイド: `{ニックネーム} [クロソイド]`

### 図形のプロパティ表示

- 右プレーンのプロパティ表示では、各種パラメータを数値入力で編集できる:

  - **直線**: 参照始点 X/Y、参照終点 X/Y
    （方向角は読み取り専用ラベルとして表示）
    - 保持する個数分の線分: 線分始点 X/Y/割合、線分終点 X/Y/割合
      （線分長は読み取り専用ラベルとして表示）
       (割合は、参照始点を 0.0、参照終点を 1.0 とした、相対位置)

  - **線分**: 始点・終点を X/Y 座標と割合 t で数値入力できる。
    - X または Y を入力すると直線に投影して他方が自動計算される（直線上に束縛）。
    - 割合 t を直接入力することもできる。
    - 線分長は読み取り専用として表示する。

  - **円**: 中心 X/Y、半径（QDoubleSpinBox で直接編集）
    - 保持する個数分の円弧: 始角・終角・弧長角・弧長（読み取り専用）

  - **円弧**: 始点・終点を以下の方法で数値入力できる。
    - 角度（度数）で直接入力する。
    - X 座標を入力すると、円上の2候補から元の位置に近い方の Y が自動計算される。
    - Y 座標を入力すると、円上の2候補から元の位置に近い方の X が自動計算される。
    - 始点・終点の X/Y 座標（ワールド座標）が常に表示される。
    - 弧長角・弧長は読み取り専用として表示する。

  - **クロソイド**: 以下を表示する（すべて読み取り専用）。
    - カーブ方向（左カーブ / 右カーブ）、反転フラグ、有効/無効状態
    - クロソイドパラメータ A = R·√(2τ)
    - 全偏角 τ [度]
    - 線側接点の X/Y 座標
    - 円側接点の X/Y 座標
    - 円弧が存在する場合、円側接点と円弧端点（左カーブ→arc.start、右カーブ→arc.end）
      との距離を表示し、一致していれば緑色、不一致なら赤色で表示する。

- **ニックネーム**:
  - 各図形（直線・円・クロソイド）に任意のニックネームを設定できる。
  - 1図形が選択されている場合、
    右プレーンの先頭にニックネーム入力欄が表示される。
    テキストを入力するとすぐに登録される。空欄にすると削除される。
  - 右プレーンの上部に「ニックネームで選択」エリアが常時表示される。
    コンボボックスが2つあり、それぞれ全図形のニックネーム一覧から選択できる。
    「選択を適用」ボタンで最大2図形を同時選択できる。
    コンボボックスにはニックネームが設定されていない図形も ID で表示される。
  - ニックネームはファイルへの保存・読み込みに対応する。

- **関連図形**

  - 右パネルにプロパティを表示している図形の情報の最後に、
    接続している図形の一覧を表示し、
    個々の図形に対して「選択」ボタンと「選択追加」ボタンを用意する。
  - 選択ボタンを押すと、その図形だけが選択される。
  - 選択追加ボタンを押すと、今選択中の図形が追加される。

### scene とキャンバスの scene 参照の一本化

`MainWindow.scene` は常に `canvas.scene` と同じ参照を返すプロパティとして実装する。
`canvas.undo()` が `Scene.from_dict()` で新しい `Scene` を生成した後も、
`MainWindow.scene` が自動的に最新の `canvas.scene` を返すため、
参照のズレが生じない。

ファイル読み込みや全削除では `self._canvas.scene = ...` で canvas 側を更新すれば
`MainWindow.scene` も自動追従する。


## 縦断線形設計ウィンドウ

縦断線形(&V) メニュー → 縦断線形ウィンドウを開く (Ctrl+Shift+V) で、
縦断線形設計の別ウィンドウが開く。縦断線形ウィンドウはメインウィンドウとは
独立して操作できる。

### 縦断線形ウィンドウのビュー

- 横軸: 距離 [m]、縦軸: 標高 [m]（上が正の数学座標系）
- マウスホイールで距離方向スケールを変更。Shift+ホイールで標高方向スケールを変更。
- 何もない場所を左ドラッグでパン。中ボタンドラッグでもパンできる。
- 全体表示 (Ctrl+0) で全図形が画面に収まるよう調整する。

### 縦断線形ウィンドウのモード

- 選択モード [S]: 勾配直線・縦断曲線を選択し、プロパティを右パネルで確認・編集する。
- 勾配直線モード [G]: 左クリックで始点→終点を指定して勾配直線を追加する。
  既存直線の末端と距離が近ければ自動的に標高を揃えて接続する。
  [Esc]キーで連続入力をリセットする。

### 縦断線形ウィンドウの右パネル

- 勾配直線を選択した場合: 始点・終点の距離と標高、勾配 [%]、水平長を表示する。
  また、この直線とその次の直線の間に縦断曲線を挿入するボタンと曲線長入力欄を表示する。
  次の直線が接続されていない場合、または既に縦断曲線がある場合はボタンが disable になる。

- 縦断曲線を選択した場合: PVI距離・PVI標高・前勾配 g1・後勾配 g2・勾配変化量を表示する。
  曲線長 L を QDoubleSpinBox で変更できる（VPT ハンドルのドラッグでも変更可能）。
  VPC距離・VPC標高・VPT距離・VPT標高・K値を設計指標として表示する。
  縦断曲線を削除するボタンを提供する。

### 平面線形との連携

縦断線形ウィンドウを開く際、平面線形画面で選択中の図形が渡される。
選択された平面線形要素（線分・クロソイド・円弧）は、snap 接続順に並べられ、
縦断キャンバス上部にカラーバーとして表示される。

カラーバーの色分け:
  - 線分: 青色
  - クロソイド: 緑色
  - 円弧: 紫色

カラーバーのラベルは「種別 [ニックネーム] 長さ」の形式で表示される。
ニックネームが設定されていない場合はニックネーム部分が省略される。
各要素の境界位置に破線の縦線を引き、縦断線形のどの距離に対応するか示す。
