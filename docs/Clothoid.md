## 座標系

本文書では、数学の座標系を採用している。

- 画面上3時方向が、x軸の伸びる方向。
- 画面上12時方向が、y軸の伸びる方向。
- 有向角の正の向きは、反時計回り。
- z軸は、x軸からy軸に回した時、右ねじの進む方向。

本アプリの実装では、モデルデータはすべてこの数学座標系（ワールド座標）で
定義・保持する。GUI描画時のみ、Canvas.w2s() によりスクリーン座標に変換する。

### ワールド座標とスクリーン座標の変換

スクリーン座標は Qt ウィジェットのピクセル座標系であり、y 軸が下向き正となる。

```
screen_x =  world_x * scale + offset_x
screen_y = -world_y * scale + offset_y   ← y 反転
```

### Qt drawArc の角度

`QPainter.drawArc(rect, startAngle, spanAngle)` の角度引数は、
スクリーン座標ではなく数学座標（y 上向き・反時計が正）として解釈される。
したがって、ワールド座標の角度をそのまま渡せばよい（符号反転は不要）。

```
startAngle_16 = int(round(angle_start_deg * 16))   ← 符号反転不要
spanAngle_16  = int(round(arc_angle_deg   * 16))   ← 正 = 反時計 (CCW)
```


## 直線

「直線」は、通過する異なる2点により定義する。
また、方向を考える。
通過する2点を、「参照始点」と「参照終点」と呼び、
参照始点から参照終点への方向ベクトルをこの直線の方向と決める。
参照始点と参照終点を合わせて「参照点」と呼ぶ。

### 直線の符号付き距離

直線の方向ベクトルを d とし、直線上の点を p0 とすると、
任意の点 m に対する符号付き距離は以下で定義する。

```
signed_dist(m) = d.cross(m - p0)   ← 左側が正
```

ここで `cross` は 2D 外積（d.x * pm.y - d.y * pm.x）である。
左側（反時計90°方向）が正、右側が負となる。

### 直線の左法線

直線の方向ベクトル d = (dx, dy) に対して、左法線（CCW 90° 回転）は:

```
left_normal = (-dy, dx)
```


## 線分

直線は、その部分として複数の「線分」を持つことが出来る。

線分はベースとなる直線上の異なる2点である「始点」と「終点」を持つ。
「参照始点」から「参照終点」へ向かうベクトルは
「始点」から「終点」へ向かうベクトルと同じ向きである必要がある。

始点と終点を合わせて「端点」と呼ぶ。

線分上の位置は、参照始点を 0.0、参照終点を 1.0 とした「割合 t」で表す。


## 線分の変形

線分は、作成後に変形することが出来る。
変形の内容は、端点に表示されるハンドルをdragするか
右パネルから数値入力を行うことで指定する。
ハンドルの移動は、常に直線上に束縛される。
右パネルからの数値入力も常に直線上に束縛されるため、
x座標またはy座標の数値入力に合わせて、y座標またはx座標の値が自動計算される。
また、割合 t を直接入力することもできる。

但し、クロソイドの端点のように、他の図形との関係で決まる端点については、
他の図形の再計算の結果が優先的される為、端点側の設定からは変形できない。


## 直線の変形

直線は、作成後に変形することが出来る。
変形の内容は、参照点に表示されるハンドルをdragするか
右パネルから数値入力を行うことで指定する。

直線の変形は、直線が持つ全ての線分に波及する。
線分の端点は、直線の参照始点を0.0、参照終点を1.0 とした
相対位置が変化しないように値が反映される。

但し、クロソイドの端点のように、他の図形との関係で決まる端点については、
他の図形の再計算の結果が優先的に反映される。

### 直線の変形時の直線上への束縛

1つの直線が選択された状態で、ハンドルをShiftキーを押しながらdragすることで、
ハンドルの移動を元の直線上に束縛することが出来る。
また、右パネルの参照始点、および、参照終点には、
「直線束縛」のラジオボタンがあり、ラジオボタンがonの時は、
x座標またはy座標を入力すると、
元の直線上に束縛されるようにy座標またはx座標の値が自動計算される。

「直線束縛」のラジオボタンが参照されるのは、x座標,y座標の数値入力時のみなので、
いずれかのラジオボタンが押されていても、
ハンドルをdrag時にshiftキーが押されていなければ、
ハンドルの移動が直線上に束縛されることはない。


## 直線と線分のGUI上の表示

ある直線をベースとする線分は、直線上に表示されるが、
GUI上の表現として線分は太く表示する等、区別できるようにする。

各線分の始点と終点は、直線の向きになっている必要がある。
これに反している場合、ユーザが認識できるように、線分の色を変える。

直線は参照点を通る無限の長さを持つが、
GUI上は、直線の参照始点と、直線が持つ各線分の始点の中で
最も直線の向きと反対側に離れた点までを描くか、
画面の端一杯までを描くかを切り替えることが出来る。
同様に、参照終点側も切り替えが出来る。


## 線分同士のsnap機能

2個の線分間のsnap機能とは、一方の線分の終点と他方の線分の始点を
常に一致させる機能である。
一致している側の端点を「snap機能の共有端点」と呼ぶ。

2個の線分を選択した状態で、右パネルから設定できる。
2個の線分が包含関係にある場合、
外側の線分の終点の値を、内側の線分の始点の値で上書きする。
それ以外の場合、参照始点に近い側の線分の終点の値を、
参照終点に近い側の線分の始点の値で上書きする。

また、snap機能を設定済みの2個の線分を選択した時に、右パネルから解除できる。

## 円弧

円は、その部分として複数の「円弧」を持つことが出来る。

円弧は、ベースとなる円上の異なる2点である「始点」と「終点」を持つ。
円は、始点と終点により、2個の円弧に分けることができるが、
始点と終点により定義される円弧とは、
始点から円上を反時計回りに進み、終点に至る側を指す。

始点と終点を合わせて「端点」と呼ぶ。

円弧の角度は数学座標系（y上向き・反時計が正）で管理する。
- `angle_start`: 始点の角度（ラジアン、x 軸正方向 = 0）
- `angle_end`:   終点の角度（ラジアン）
- `arc_angle()`: `(angle_end - angle_start) % (2π)` で常に正の値をとる。
                 これが反時計回りの弧長角度となる。


## 円弧の変形

円弧は、作成後に変形することが出来る。
変形の内容は、端点に表示されるハンドルをdragするか
右パネルから数値入力を行うことで指定する。
右パネルから数値入力を行う場合、
x軸の正方向を0度として、角度で指定することも出来る。
右パネルから数値入力を行う場合、端点は円上に束縛されるが、
x座標またはy座標が指定された場合、
円上の座標のy座標またはx座標の候補は2個ありえる。
元のy座標またはx座標に近い方が自動的に選択される。


## 円の変形

円は、作成後に変形することが出来る。
変形の内容は、参照点に表示されるハンドルをdragするか
右パネルから数値入力を行うことで指定する。

円の変形は円弧に波及し、円弧は中心に対する角度を保つ。


## 円と円弧のGUI上の表示

円弧がある円は、描画において円弧のみを実線で強調表示し、
円の輪郭全体は薄い点線で表示する。


## 円弧同士のsnap機能

2個の円弧間のsnap機能とは、一方の円弧の終点と他方の円弧の始点を
常に一致させる機能である。
一致している側の端点を「snap機能の共有端点」と呼ぶ。

2個の円弧を選択した状態で、右パネルから設定できる。
最初に選択した円弧の終点の値を、2番目に選択した円弧の始点に上書きする。

また、snap機能を設定済みの2個の円弧を選択した時に、右パネルから解除できる。


## クロソイド

「クロソイド」は、直線と円より定義する。
直線から円弧へ移行するクロソイド曲線を表す。
つまり、直線上を、直線の方向ベクトルの方向に進む点（線側接点）から始まり、
曲線長に比例して曲率を変化させながら（Euler spiral / Cornu spiral）、
曲率が円の曲率 1/R と一致した点（円側接点）で円に接続する曲線を指す。

内部的には Fresnel 積分により正確に計算する。
描画点は、接線方向の変化量が一定になるよう（等接線角度変化）配置し、
また、ビュースケールに応じて点の密度を動的に変化させることで、
ズームインしても滑らかな曲線として表示される。

### クロソイドの計算アルゴリズム

クロソイドの計算は、添付の `Clothoid.py` のロジックを使用する。
scipy 等の外部ライブラリは不要で、純粋な Python で実装する。

#### Fresnel 積分 `_fresnel_xy_tau(tau, R)`

弧長 L = 2R·τ、クロソイドパラメータ A² = R·L として、
クロソイド終点の局所座標変位 (xe, ye) を台形則で数値積分する。

```
L = 2 * R * tau
A2 = R * L
xe = Σ cos(s²/2A²) * ds
ye = Σ sin(s²/2A²) * ds
```

#### 存在条件の判定 `_find_tau(R, d_abs)`

直線から円の中心への垂直距離 d_abs に対し、
Fresnel 条件 `ye(τ) = d_abs - R·cos(τ)` を満たす全偏角 τ を
二分法（80 回反復）で解く。

存在条件: `d_abs > R`（直線が円の外側にある場合のみ解が存在する）。

#### 接点の計算

```python
proj_center = eln.project(circle.center)   # 円の中心から直線への垂線の足
direction   = eln.direction                 # 実効直線の方向ベクトル
left        = eln.left_normal               # 左法線 = CCW 90° 回転
sign        = +1.0 if d_signed > 0 else -1.0  # 円が左側なら +1

# 円側接点 cc
cc = proj_center + direction * R * sin(τ) + left * sign * (d_abs - R * cos(τ))

# 線側接点 lc
lc = proj_center + direction * (R * sin(τ) - xe)
```

#### 点列の生成

等接線角度変化方式により、曲率の大きい部分で点が密になるよう配置する。

```
s_i = sqrt(2 * A² * θ_i),  θ_i = i * τ / n_steps
```

内部では小ステップで Fresnel 積分を蓄積しながら、
出力弧長位置 s_i に到達した時点で点を emit する。


### クロソイドが存在する条件

円の中心から直線への垂直距離を d、円の半径を R とする。

d ≤ R の場合（直線が円の内部を通る、または円に接する場合）、
クロソイドは存在しない。

d > R の場合（直線が円の外側にある場合）、
Fresnel 積分の条件 y(τ) = d - R·cos(τ) を満たす全偏角 τ が
(0, 2π) の範囲に存在するとき、クロソイドが一つ存在する。
d が R に比べてあまりにも大きい場合は解が存在せず、
この場合もクロソイドは存在しない。


### クロソイドのカーブの方向

直線の方向ベクトルを基準に、円の中心が直線の左側にある場合、
クロソイドは左カーブとなる。
円の中心が直線の右側にある場合、クロソイドは右カーブとなる。

実装上の判定:

```python
d_signed = eln.signed_dist(circle.center)  # 左側が正
is_left_curve = d_signed > 0
```

ここで `signed_dist` は `direction.cross(p - ref_start)` で計算する
（2D 外積、左側が正）。


### クロソイドのsnap機能

クロソイドを表すデータ構造には、2種類の boolean 値を持つ。
- 線分とのsnap機能
- 円弧とのsnap機能

線分のベースとなる直線と円弧のベースとなる円から定義されるクロソイドを考える。

クロソイドの線分とのsnap機能が on の場合、
接点に最も近い線分を対象として、クロソイドの反転フラグが
- off の場合、線分の終点をクロソイドとの接点に一致させる。
- on の場合、線分の始点をクロソイドとの接点に一致させる。

尚、線分の端点の、snapと逆側は、他の接続等で束縛されていない場合は、
線分の向きを基準に、線分の長さが正になるようにし、
非正となる場合は、一定の長さとなるように調整する。
ここで「他の接続等で束縛されている」とは、
同じ直線の線分の逆側端点を参照する別のクロソイドの snap 機能が on
であることを指す。

クロソイドの円弧とのsnap機能が on の場合、
接点に最も近い円弧に対し、

- クロソイドが**左カーブ**の場合、円弧の**始点**をクロソイドの円側接点に一致させる。
- クロソイドが**右カーブ**の場合、円弧の**終点**をクロソイドの円側接点に一致させる。

これは数学座標系（y上向き・反時計が正）の定義に基づく。
arc_angle = (angle_end - angle_start) % (2π) が CCW の弧長角度となる。

円弧とのsnap機能が on のとき、円弧がまだ存在しない場合は自動的に生成される。
この場合、円弧の中心角が45度となるように他の端点を設定する。

- 左カーブ: `angle_start = circle_pt の角度`、`angle_end = angle_start + π/4`
- 右カーブ: `angle_end = circle_pt の角度`、`angle_start = angle_end - π/4`

スムーズ接続で作られた左カーブ・右カーブの2本のクロソイドがある場合、
両方のsnap機能により円弧の始点と終点がそれぞれ設定される。

- 左カーブ(lb側)接点 → arc.angle_start
- 右カーブ(la側)接点 → arc.angle_end
- arc_angle ≈ 222° の大きい弧（CCW）
- 道路は arc.end → arc.start 方向（CW）に通る（内側の小さい弧）

直線や円が移動・変形した場合、snap機能が on のクロソイドは
自動的に再計算され、端点が更新される。


### クロソイドの反転

クロソイドは「直線方向の反転フラグ」を持つ。通常は登録された直線の方向
（参照始点 → 参照終点）と一致するが、反転フラグを切り替えることで
参照始点と参照終点を入れ替えた向きとして扱える。

反転操作は、直線オブジェクト自体は変更せず反転フラグのみを切り替える。
これにより、直線が移動・変形しても常に追従できる。

実装では、反転フラグが on の場合に `ref_start` と `ref_end` を入れ替えた
仮想の実効直線（`_effective_line()`）を生成して計算に使用する。

反転操作後も snap機能の値は維持される。
snap が on の場合、反転後の実効直線と円に基づいて端点が更新される。

同じ直線・円の組に対してクロソイドが2本ある場合、
それぞれのクロソイドは互いに逆の反転フラグを持つ（一方が off、他方が on）。
この状態では個々のクロソイドの反転操作は行えない。


## 2直線の接続

2直線の接続状態は、次のいずれかを1つになる。

- 折れ線接続
- スムーズ接続
- 接続無し

「接続なし」では、2直線は互いに影響し合わない。

2直線の接続情報は `LineConnection` オブジェクトとして管理し、
以下のフィールドを持つ。

- `kind`: `"polyline"` または `"smooth"`
- `line_a`, `line_b`: 接続する2直線への参照
- `shared_point`: 共有参照点の座標
- `a_end_is_shared`: line_a の `ref_end` が共有点か（False なら `ref_start`）
- `b_start_is_shared`: line_b の `ref_start` が共有点か（False なら `ref_end`）
- `circle`: スムーズ接続時の円への参照
- `bisector_dir`: 角の二等分線方向ベクトル


## 折れ線接続

2個の直線間の折れ線接続とは、一方の直線の参照点と他方の直線の参照点を
常に一致させる機能である。
一致している側の端点を「共有参照点」と呼ぶ。
共有参照点は、参照始点と参照終点の組合せになるとは限らないことに注意すること。

2個の線分を選択した状態で、右パネルから設定できる。
2直線の交点を算出し、共有参照点とした上で、
それぞれの直線で共有参照点に近い側の参照点を共有参照点の座標で上書きする。
直線が持つ線分にも変更の影響が波及することに注意する。

また、折れ線接続を設定済みの2個の線分を選択した時に、右パネルから解除できる。

折れ線接続がonの直線では、参照共有点のハンドルをdragすると、
両方の直線に変化が波及する。
また、一方の直線が選択され、かつ、Shiftキーも押されている場合、
直線への束縛が適用され、同時に選択されていない方の直線の参照点も追従する。

### 共有点ハンドルの実装

折れ線接続後、共有参照点の位置には1つの交点ハンドル（`shared_pt`）のみを表示する。
共有点と重なる `line_ref_start/end` や `seg_start/end` ハンドルは非表示にし、
`shared_pt` のドラッグで確実に両直線が追従するようにする。

ドラッグ中は `LineConnection.a_end_is_shared` / `b_start_is_shared` フラグを参照して、
毎フレーム正確にどちらの参照点を更新すべきかを判定する。


## スムーズ接続

直線 A と 直線 B を「スムーズ接続」する手順は以下の通り。

以下のいずれかに当てはまる場合、手順を失敗させる。
- 直線 A と 直線 B が平行、つまり、2直線の方向ベクトルのなす角が
  0度か、180度の場合
- 直線 A が線分を持たない場合
- 直線 B が線分を持たない場合

手順-1:
直線 A と 直線 B を折れ線接続する。
2直線の交点を X とする。
接続後の直線 A の端点の X と異なる側を P とする。
接続後の直線 B の端点の X と異なる側を Q とする。

手順-2:
方向ベクトル PX から方向ベクトル XQ への有向角の正弦(sin)が非負の場合、
参照始点 P、参照終点 X の直線を J とする。
参照始点 Q、参照終点 X の直線を K とする。
方向ベクトル PX から方向ベクトル XQ への有向角の正弦(sin)が負の場合、
参照始点 Q、参照終点 X の直線を J とする。
参照始点 P、参照終点 X の直線を K とする。

尚、J, K はスムーズ接続の手順を示す為に便宜上定義される直線である。
本アプリで保持するデータとしてはそれぞれ元の直線 A, B (または B, A) への参照と
方向を反転するかどうかを示すフラグの組合せ等により実現する。

直線 J の X と異なる側の端点を U とする。
直線 K の X と異なる側の端点を V とする。

これにより、
直線 J は、方向ベクトル UX となり、
直線 K は、方向ベクトル VX となり、
UXからXVへの有向角は 180度以下となる。

手順-3:
角 UXV の角の二等分線 D を算出する。

二等分線の方向は以下で計算する。

```
XU = (U - X).normalized()
XV = (V - X).normalized()
bisect = (XU + XV).normalized()
```

これにより bisect は折れ角の内側（小さい角度側）を向く。

手順-4:
角の二等分線 D 上に中心を持つ円 C を追加する。
円の半径と直線からの距離はデフォルト値を選択する。
デフォルトでは、直線からの距離 d が半径 R の 1.5 倍になるよう配置する
（クロソイド存在条件 d > R を満たす）。

手順-5:
直線 J と円 C からクロソイド E を作成する。
クロソイド E は必ず 左カーブになる。
クロソイド E の線分 J とのsnap機能の初期値を on にする。
クロソイド E の円弧 C とのsnap機能の初期値を on にする。

手順-6:
直線 K と円 C からクロソイド F を作成する。
クロソイド F は必ず 右カーブになる。
クロソイド F の線分 K とのsnap機能の初期値を on にする。
クロソイド F の円弧 C とのsnap機能の初期値を on にする。

スムーズ接続されている場合、以下のような動作になる。

- クロソイド E と F の円弧とのsnap機能が on であるため、
  スムーズ接続後、円 C に円弧が自動生成される。

- 円 C の中心は、直線 A と 直線 B がスムーズ接続されている間は
  角の二等分線 D 上に束縛される。

- 直線 A, B の交点ハンドルを動かすと、円 C も連動して二等分線上を移動する。

- 直線 A または B の参照点を動かすと、2直線の交点が再計算され、
  円 C も連動して二等分線上を移動する。
  つまり、参照点の移動によっても円は追従する。

### スムーズ接続時の円の追従

直線参照点が動いた際、スムーズ接続の円を追従させる処理 `_update_smooth_circle` は
以下の手順で実行される。

1. 2直線の新しい交点 `new_ix` を計算する。
2. 両直線の「共有点と反対側の端点」P, Q を求め、二等分線方向 `bisect` を再計算する。
3. 旧 bisector 上での円の距離 `t = (center - bisector_origin) · bisector_dir` を保持する。
4. 円の新しい中心を `new_ix + bisect * t` とする。
5. `bisector_origin`, `bisector_dir` を更新する。


## ニックネーム

各図形（直線・円・クロソイド）には、任意のニックネームを設定できる。
ニックネームは図形 ID をキー、文字列を値とする辞書として管理され、
JSON ファイルへの保存・読み込みにも対応する。

ニックネームはUIで、図形を選択する用途に使用する。
その為、ニックネームはユニークにしなければならない。
ニックネームは、UIから変更出来る。
新たに追加した図形には、defaultのニックネームを付与する。
defaultの値は、`nickname_<図形type>_<図形ID>`とする。
ex) `nickname_line_6`

右パネルにプロパティを表示している図形の情報の最後に、
接続している図形の一覧を表示し、
個々の図形に対して「選択」ボタンと「選択追加」ボタンを用意する。
選択ボタンを押すと、その図形だけが選択される。
選択追加ボタンを押すと、今選択中の図形が追加される。

ニックネームは縦断線形の設計画面において、対応する平面線形要素の
カラーバーラベルとして表示される。


## 縦断線形

縦断線形は、道路を側面から見た高さの変化を設計するためのものである。
平面線形（直線・円弧・クロソイド）と組み合わせて3D道路形状を定義する。

縦断線形は平面線形と独立したデータとして管理される。
縦断線形の設計は別ウィンドウ（縦断線形ウィンドウ）で行う。

### 勾配直線 (GradeLine)

縦断線形の直線区間。始点・終点をそれぞれ (距離, 標高) の組で定義する。
勾配 [%] = (終点標高 - 始点標高) / (終点距離 - 始点距離) × 100

### 縦断曲線 (VerticalCurve)

隣接する2本の勾配直線をつなぐ放物線区間。

PVI (Point of Vertical Intersection): 2勾配線の交点 (距離, 標高)
曲線長 L: VPC (曲線始点) = PVI - L/2、VPT (曲線終点) = PVI + L/2

放物線式 (VPC を原点とする局所座標 x):
  y(x) = elev_vpc + g1/100 · x + (g2 - g1) / (2L) / 100 · x²
  ここで g1, g2 は勾配 [%]

凸型 (g1 > g2): 山形、凹型 (g1 < g2): 谷形。
K 値 = L / |g2 - g1| (縦断曲線の緩やかさの指標)。

### 縦断線形の操作

隣接する2本の勾配直線の間に縦断曲線を挿入できる。
縦断曲線を挿入すると、両側の勾配直線がVPC/VPTまで短縮される。
縦断曲線の曲線長は、右パネルの数値入力またはVPTハンドルのドラッグで変更できる。
縦断曲線を削除すると、両側の勾配直線がPVIまで延長されて再接続される。
