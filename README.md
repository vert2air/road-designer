# 道路設計アプリ

## 必要環境
- Python 3.10+
- PyQt6
- NumPy
- SciPy

## インストール
```bash
pip install PyQt6 numpy scipy
```

## 起動
```bash
python main.py
```

## ファイル構成
| ファイル | 役割 |
|---|---|
| `main.py` | エントリーポイント |
| `models.py` | データモデル (Line, Circle, Clothoid, Scene 等) |
| `canvas.py` | メイン編集キャンバス (描画・マウス操作) |
| `right_panel.py` | 右パネル (プロパティ・操作UI) |
| `vertical_window.py` | 縦断線形設計ウィンドウ |
| `main_window.py` | メインウィンドウ (メニュー・ツールバー) |

## 主な操作

### モード切り替え
| キー | モード |
|---|---|
| S | 選択モード |
| L | 直線モード |
| C | 円モード |

### 直線モード
- 左クリック: 始点/終点を指定 (折れ線を連続入力)
- Esc: 連続入力をリセット

### 円モード
- 左クリックしてドラッグ: 中心と半径を指定して円を作成

### 選択モード
- 左クリック: 図形を選択
- Shift+クリック: 複数選択
- Del: 選択図形を削除

### ビュー操作
- マウスホイール: ズームイン/アウト (マウス位置中心)
- 左ドラッグ (図形なし): パン
- 中ボタンドラッグ: パン

### ショートカット
| ショートカット | 機能 |
|---|---|
| Ctrl+S | 上書き保存 |
| Ctrl+Shift+S | 名前を付けて保存 |
| Ctrl+O | ファイルを開く |
| Ctrl+Z | 元に戻す (最大500) |
| Ctrl+0 | 全体表示 |
| Ctrl+Shift+V | 縦断線形ウィンドウを開く |

## 実装済み機能

### 平面線形
- 直線の作成・編集 (参照始点/終点、線分)
- 円の作成・編集 (中心、半径、円弧)
- クロソイド (Fresnel積分による正確な計算)
  - d/R ∈ (1, ~2.17) のとき自動計算
  - 線分/円弧への snap 機能
  - 反転フラグ (同一直線・円に2本作成可能)
- 折れ線接続・スムーズ接続・接続解除
- ハンドルによる各種図形の変形
- undo (最大500手順)

### ニックネーム
- 各図形に任意のニックネームを設定
- ニックネームで選択 (右パネル)
- JSON 保存/読み込み対応

### ファイル
- `.rdjson` 形式での保存/読み込み

### 縦断線形
- 勾配直線の作成
- 縦断曲線 (放物線) の挿入
- VPC/VPT/K値の自動計算
- 平面線形カラーバー表示

## クロソイドの数学

クロソイドの存在条件方程式:

```
u · y(u) + cos(u²/2) = d/R
```

ここで:
- `u = A/R` (A: クロソイドパラメータ)
- `y(u) = ∫₀^u sin(t²/2) dt` (Fresnel積分)
- `d`: 直線から円の中心への垂直距離
- `R`: 円の半径
- 解の存在範囲: `d/R ∈ (1, ≈2.169)`

scipy.optimize.brentq で数値的に解き、点列は等接線角度変化でサンプリング。
